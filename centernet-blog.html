Understanding CenterNet: Object Detection via Center Points

As a major milestone in anchor-free detection, CenterNet treats objects as single points. This approach is often more versatile than traditional anchor-based methods, making it easier to adapt for tasks like pose estimation and segmentation.

📅 March 28, 2026 • ✍️ MD Shafaque • ⏳ 20 min read

Introduction

Object detection is a computer vision technique to localize and classify objects in an image or video. The deep learning-based object detection technique is highly successful with many applications using object detection, for example, surveillance and tracking.

What is an Anchor in Object Detection?

Anchors are predefined bounding boxes that act as initial guesses for locating objects in an image. They serve as reference proposals that the model uses to predict the actual object positions. To understand this, consider an image of size 300 × 300 divided into a 3 × 3 grid. At the center of each grid cell, a bounding box of fixed size (for example, 80 × 75) is placed. These predefined boxes are called anchors. During training, each anchor is compared with the ground truth bounding boxes. If an anchor overlaps sufficiently with a ground truth object, it is assigned the corresponding class label. Otherwise, it is labeled as background (no object). Additionally, a single grid cell can contain multiple anchors of different sizes and shapes, allowing the model to detect objects with varying dimensions more effectively.

What is Anchor-Free Object Detection?

Anchor-free object detection is a method that predicts object bounding boxes directly, without using predefined anchor boxes. Instead, predictions are made relative to specific reference points in the image, typically grid cells.

For example,

Consider an image divided into a 6 × 6 grid. The center of an object will lie within one of these grid cells. That particular cell is responsible for predicting the object’s properties, including its width, height, and the offset of its center from the grid cell’s center. This approach simplifies the detection process by eliminating the need for predefined anchors and focuses on predicting objects based on their key points.

Is Anchor Free Better Than Anchor-based Object Detection?

Initially, anchor-based object detection achieved strong results and became more accurate due to extensive research and improvements. However, recent advancements in anchor-free methods have closed this gap, making their performance comparable in terms of accuracy.

💡 Advantages of anchor-free methods over anchor-based approaches:
  • No need for anchor design: Selecting appropriate anchor box sizes and shapes is critical in anchor-based methods, but it is complex and often requires extensive hyperparameter tuning.
  • Simpler and faster models: Increasing the number of anchors can improve accuracy in anchor-based methods, but it also increases model complexity and slows down inference. Anchor-free methods avoid this overhead.
  • Better generalization: Anchor-free approaches represent objects as key points, making them easier to extend to tasks like keypoint detection, pose estimation, and 3D object detection. In contrast, anchor-based methods are mainly limited to bounding box prediction.
  • Improved performance: Anchor-free methods have achieved state-of-the-art performance on various object detection benchmarks.

Components of Deep Learning-Based Object Detection

Before understanding how CenterNet works, it is important to know the general pipeline of deep learning-based object detection. An object detection system mainly consists of four key components:

  • Object Detection Model: A neural network that processes the input image and extracts features to identify objects.
  • Ground Truth Encoding: The process of converting actual object labels into a format that matches the model’s output structure.
  • Loss Function: A function used to measure the difference between predicted outputs and actual labels, guiding the model during training.
  • Model Prediction Decoding: The step of converting the model’s output back into meaningful predictions, such as object classes and bounding box coordinates.

    • Object Detection Model

    A Convolutional Neural Network (CNN)-based architecture is used to process input images and convert them into lower-resolution feature maps. These feature maps contain important information about objects in the image, including their locations and class labels. However, a basic CNN is not highly effective for object detection tasks because deeper layers tend to lose precise spatial (localization) information. To overcome this limitation, advanced architectures such as Feature Pyramid Networks (FPN) are used, which help preserve both semantic and spatial details for better detection performance.

    Ground Truth Encoding in Object Detection

    To compute the loss between the model’s predictions and the ground truth labels, both must have the same shape and format. In this case, the model produces an output of size C × 3 × 3. However, the ground truth labels are typically represented in a different format, such as class IDs along with bounding box coordinates. The model produces an output of size C × 3 × 3, whereas ground truth labels are typically represented as [class_id, x_min, y_min, x_max, y_max]. To enable proper comparison during training, these labels must be converted into the same format as the model output. This process is known as ground truth encoding.

    Loss Function in Object Detection

    Training an object detection model requires a loss function, similar to other neural networks. The problem consists of two main tasks:

  • Localization: Predicting bounding box coordinates, which is a regression problem.
  • Classification: Identifying the object class, which is a classification problem.
    • To handle both tasks, separate loss functions are used, and their weighted combination forms the final loss. Since background regions significantly outnumber object regions, the problem suffers from class imbalance. To address this, specialized loss functions such as focal loss are used, which reduce the impact of easily classified examples.

    Model Prediction Decoding

    After prediction, the model output must be converted back into a meaningful format, such as [class_id, x_min, y_min, x_max, y_max]. This step is called prediction decoding, and it is essentially the reverse of ground truth encoding.

    Introduction to CenterNet

    Now that the core components of object detection are clear, we can understand how CenterNet builds on them.

    In April 2019, two important papers were introduced at CVPR:

    Object as Points by Xingyi Zhou, Dequan Wang, and Philipp Krähenbühl
    CenterNet: Keypoint Triplets for Object Detection by Kaiwen Duan and others

    In the Object as Points paper, the term CenterNet is used to describe the algorithm. To understand how CenterNet works, we focus on the following aspects:

    • Ground truth encoding
    • Model prediction decoding
    • CenterNet model architecture (backbone)

    Ground Truth Encoding in CenterNet

    In CenterNet, an object is represented by the center point of its bounding box. The size of the bounding box and other object properties are derived from the keypoint features at this central location.

    Ground truth encoding in CenterNet depends on the structure of the model’s output. Therefore, it is important to first understand the model output before discussing the encoding process.

    CenterNet Output Heads and Keypoint Heatmap

    The CenterNet model consists of three output heads: the keypoint heatmap, object size, and local offset. It takes an input image of shape 3 × W × H. Given an output stride R, the output feature map has dimensions ⌊W/R⌋ × ⌊H/R⌋.

    Each output head has a specific depth: the keypoint heatmap has C channels (one for each object class), while both the object size and local offset heads have a depth of 2.

    The keypoint heatmap assigns one channel per object class (for example, 80 channels for the COCO dataset). It is responsible for encoding and predicting the center points of objects.

    Let \( p = (p_x, p_y) \) be the center of a bounding box in the original image. Due to the stride \( R \), this point is mapped to heatmap space as \( \tilde{p} = (\lfloor p_x/R \rfloor, \lfloor p_y/R \rfloor) \).

    The ground truth heatmap value at position \( (x, y) \) for class \( c \) is computed using a Gaussian distribution centered at \( \tilde{p} \):

    \[ Y_{xyc} = \exp\left( - \frac{(x - \tilde{p}_x)^2 + (y - \tilde{p}_y)^2}{2\sigma_p^2} \right) \]

    Here, \( \sigma_p \) is the standard deviation, which adapts based on the object size. It is calculated as:

    \[ \sigma_p = \frac{r}{3} \]

    where r is a radius determined such that the generated bounding box maintains a minimum IoU (Intersection over Union) with the ground truth.

    If multiple instances of the same class exist in an image, the heatmap value at each location is taken as the maximum among all corresponding instances.

    Loss Functions in CenterNet

    Since the CenterNet model has three output heads, it uses three corresponding loss functions:

    • Heatmap Loss
    • Offset Loss
    • Object Size Loss

    Let the ground truth and predicted values be denoted as follows:

    \( \text{heatmap}_{gt}: Y_{xyc} \)     \( \text{heatmap}_{pred}: \hat{Y}_{xyc} \)
    \( \text{offset}_{gt}: O_{\tilde{p}} \)     \( \text{offset}_{pred}: \hat{O}_{\tilde{p}} \)
    \( \text{size}_{gt}: s_{\tilde{p}} \)     \( \text{size}_{pred}: \hat{s}_{\tilde{p}} \)

    Heatmap Loss

    The heatmap loss is based on focal loss, which is designed to handle class imbalance by reducing the contribution of easy (well-classified) examples and focusing more on hard ones.

    For positive samples (\( Y_{xyc} = 1 \)), the loss encourages the model to predict high confidence:

    \[ L = (1 - \hat{Y}_{xyc})^\alpha \log(\hat{Y}_{xyc}) \]

    For negative samples, the loss is:

    \[ L = (1 - Y_{xyc})^\beta (\hat{Y}_{xyc})^\alpha \log(1 - \hat{Y}_{xyc}) \]

    Here, \( \alpha \) and \( \beta \) are hyperparameters. The term \( (1 - Y_{xyc})^\beta \) reduces the penalty for points near object centers, making the model focus more on truly negative regions.

    Overall, focal loss ensures that confident predictions contribute less to the loss, making it effective for handling class imbalance.

    Offset Loss

    The offset loss uses Mean Absolute Error (MAE):

    \[ L_{off} = \frac{1}{N} \sum |\hat{O}_{\tilde{p}} - O_{\tilde{p}}| \]

    This loss is computed only at object center points (keypoints) in the output space.

    Object Size Loss

    The object size loss also uses Mean Absolute Error (MAE):

    \[ L_{size} = \frac{1}{N} \sum |\hat{s}_{\tilde{p}} - s_{\tilde{p}}| \]

    Similar to offset loss, it is calculated only at the bounding box centers.

    CenterNet Model (Backbone Architecture)

    CenterNet uses different backbone architectures to extract features from input images. The main backbones used are:

    • ResNet
    • Deep Layer Aggregation (DLA)
    • Stacked Hourglass Network

    These backbones are often enhanced with upsampling layers (up-convolutions) to improve resolution and with deformable convolutions to better handle geometric variations in objects.

    CenterNet Pose Estimation

    Before understanding how CenterNet performs pose estimation, let us briefly recall how it solves the object detection problem.

    CenterNet predicts the following components for object detection:

    • Heatmap: Each class has one channel to predict its keypoints (object centers).
    • Offset: Improves the precision of predicted keypoints.
    • Object Size: Predicts the width and height of the object at its center.

    In pose estimation, CenterNet extends this idea to detect human joints as keypoints.

    Key Components in Pose Estimation

    • Joint Heatmap: Each joint type is treated as a separate class. If there are k joints, the heatmap has k channels.
    • Joint Offset: Refines the predicted positions of joints to improve accuracy.
    • Joint Locations: Predicts the positions of joints relative to the object center. For k joints in 2D space, 2k values are predicted.

    Decoding in Pose Estimation

    Decoding involves extracting keypoints from the heatmap based on a threshold value (e.g., 0.1). These keypoints are then mapped to the object center using the predicted joint locations.

    The mapping is performed by minimizing the distance between predicted joints and object centers. The heatmap prediction determines the final keypoints.

    Finally, each object center is associated with its corresponding keypoints, completing the pose estimation process.

    CenterNet Results

    CenterNet demonstrates a strong balance between speed and accuracy, outperforming several state-of-the-art object detection models.

    The speed vs. accuracy trade-off shows that CenterNet achieves higher Average Precision (AP) with competitive inference time.

    AP (Average Precision) is the standard metric used to evaluate object detection performance.

    Inference Strategies for AP Calculation

    • NA: Inference using the original image.
    • F: Inference using both original and flipped images, with predictions averaged.
    • MS: Inference using original, flipped, and multi-scale images, followed by Non-Maximum Suppression (NMS).

    Inference Strategies and Sample Prediction

    CenterNet uses three augmentation strategies for Average Precision (AP) calculation:

    • NA: Inference using the original image.
    • F: Inference using both original and flipped images, with predictions averaged.
    • MS: Inference using original, flipped, and multi-scale images, followed by Non-Maximum Suppression (NMS).

    The FPS values are reported using images of size 512 × 512 on a TITAN-V GPU.

    Filter Confident Predictions

    To retain only high-confidence detections, we filter predictions based on a threshold score.

    Python 
    def filter_detections_on_score(boxes, scores, classes, score_thresh=0.3):
    ids = np.where(scores >= score_thresh)
    return boxes[ids], scores[ids], classes[ids]

score_thresh = 0.30
bboxes, scores, classes = filter_detections_on_score(bboxes, scores, classes, score_thresh)

    Convert Normalized Coordinates to Pixel Values

    Bounding box coordinates are normalized. We convert them into pixel values based on image dimensions.

    Python 
    def normalize_to_pixels_bboxs(bboxes, img):
    img_height, img_width, _ = img.shape
    bboxes[:, 0] *= img_height
    bboxes[:, 1] *= img_width
    bboxes[:, 2] *= img_height
    bboxes[:, 3] *= img_width
    return bboxes.astype(int)

bboxes = normalize_to_pixels_bboxs(bboxes, img1)

    Annotate Predictions on Image

    Python 
    def add_prediction_to_image(img, bboxes, scores, classes, id_class_map=category_index, colors=COLOR_IDS):
    img_with_bbox = img.copy()
    for box, score, cls in zip(bboxes, scores, classes):
        top, left, bottom, right = box
        class_name = id_class_map[cls]

        color = tuple(colors[cls % len(COLOR_IDS)].tolist())[::-1]
        img_with_bbox = cv2.rectangle(img_with_bbox, (left, top), (right, bottom), color, 2)

        display_txt = '{}: {:.2f}'.format(class_name, score)
        img_with_bbox = cv2.putText(img_with_bbox, display_txt, (left, top), 
                                   cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 0), 1)

    return img_with_bbox

    Wrap-Up: Inference, Annotation, and Plotting

    Now we combine all steps into a single pipeline for inference, filtering, and visualization.

    Python 
    def infer_and_add_prediction_to_image(img, model, score_thresh=0.3):
    prediction = model(np.array([img]))
    bboxes, scores, classes = to_numpy(prediction)

    bboxes, scores, classes = filter_detections_on_score(bboxes, scores, classes, score_thresh)
    boxes = normalize_to_pixels_bboxs(bboxes, img)

    img_with_bboxes = add_prediction_to_image(img, boxes, scores, classes)
    return img_with_bboxes

    Conclusion

    • CenterNet (Objects as Points) is an anchor-free object detector with strong generalization ability.
    • It can be extended to tasks like pose estimation and 3D object detection.
    • It uses heatmaps to detect object centers, eliminating the need for NMS in some cases.
    • TensorFlow Hub provides pre-trained CenterNet models for easy inference and fine-tuning.
